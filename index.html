ÁREA DE ESTUDO

Front-End

O Front-End é a parte de uma aplicação com a qual as pessoas interagem diretamente no navegador.

O que envolve?

HTML organiza o conteúdo e dá estrutura à página. CSS define o visual, o posicionamento e a adaptação a diferentes telas. JavaScript acrescenta comportamento e interatividade.

O que busco desenvolver

  • Interfaces claras e fáceis de utilizar.
  • Layouts responsivos para computadores e celulares.
  • Interações com JavaScript e manipulação do DOM.
  • Boas práticas de semântica e acessibilidade.

Como isso aparece nos projetos

O objetivo é transformar ideias em interfaces funcionais, organizando o código para facilitar testes, manutenção e evolução. Os conhecimentos e tecnologias de cada projeto devem ser apresentados de acordo com o que foi realmente utilizado.

ÁREA DE ESTUDO

Back-End

O Back-End cuida da lógica que funciona por trás de uma aplicação: recebe informações, aplica regras e organiza a comunicação entre sistemas.

O que envolve?

Dependendo do projeto, o Back-End pode incluir lógica de negócio, APIs, validação de dados, autenticação e integração com bancos de dados. Linguagens e ferramentas como Python e Node.js podem ser utilizadas nesse contexto.

O que busco desenvolver

  • Raciocínio lógico e organização do código.
  • Processamento e validação de informações.
  • Comunicação entre aplicações por APIs.
  • Fundamentos de bancos de dados e segurança.

Como isso aparece nos projetos

Uma aplicação bem estruturada precisa tratar entradas inesperadas, comunicar erros com clareza e manter suas regras consistentes. Conforme novos projetos forem desenvolvidos, esta seção pode apresentar exemplos concretos dessas soluções.

PROCESSO DE DESENVOLVIMENTO

Vibe Coding

Uso de ferramentas de inteligência artificial como apoio ao desenvolvimento, sem deixar de revisar e compreender o código produzido.

Como utilizo a IA

A IA pode ajudar a explorar abordagens, criar uma primeira versão de funcionalidades, explicar erros e sugerir melhorias. As sugestões precisam ser analisadas, testadas e ajustadas ao objetivo do projeto.

Etapas do processo

  • Definir o problema e o resultado esperado.
  • Usar a IA para explorar possíveis soluções.
  • Revisar o código e entender as alterações propostas.
  • Testar o comportamento e corrigir problemas.

Projeto em destaque: Laboratório de Gravitação

Problema: compreender interações gravitacionais apenas por fórmulas pode ser difícil.

Ideia: criar uma simulação visual para explorar corpos celestes e observar suas interações.

Uso da IA: apoiar a implementação e a identificação de erros, avaliando as sugestões em vez de aceitá-las automaticamente.

Resultado: uma aplicação interativa baseada na Lei da Gravitação Universal de Newton, conforme a implementação atual do projeto.
